# Contributors

PowerChain Renewables Copilot is maintained as part of the PowerChain project.

## Contributor record

The authoritative contributor history is the repository's version-control history. This file intentionally does not invent personal names or attribution that is not present in the repository metadata.

## How to contribute

See [`docs/CONTRIBUTING.md`](docs/CONTRIBUTING.md) for development workflow, validation requirements, architecture rules and security-sensitive review expectations.

## Contribution areas

Contributions are welcome across:

- renewable-energy operations and forecasting
- local/P2P energy markets
- carbon and tokenized-energy workflows
- GRIDLLM agents, skills and AI provider adapters
- Solana/SVM, Sui, Helius, Pyth and oracle infrastructure
- Supabase/Prisma persistence
- UI/UX, accessibility and responsive behavior
- testing, security, documentation and observability

All contributions must preserve the project's non-custodial rule: AI and server components may analyze, construct and simulate, but user wallets own signing authority.
